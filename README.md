# Money Psychology | No BS — Media Assets

Public media assets for [@psy_money1](https://t.me/psy_money1).

## Structure
- `telegram/YYYY-MM/`: images available by public HTTPS links
- `sources/`: editable designs
- `posts/`: captions, scheduled content, publication notes

## Publishing
1. Prepare creative and factual caption.
2. Upload image into `telegram/YYYY-MM/` in JPEG or PNG format.
3. Verify the direct `raw.githubusercontent.com` link returns a valid image.
4. Validate the caption and media with Zernio.
5. Publish and verify the resulting Telegram message URL.

**Do not upload secrets, private data or third-party copyrighted images without permission.**
